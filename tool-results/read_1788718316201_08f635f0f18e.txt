    51→Stage Summary:
    52→- KNOWLEDGE BASE ACQUIRED (key models to apply later):
    53→  1. REFRAME: model = rented commodity (API); product = orchestration layer. Moat = UX, memory, integrations, trust, niche — never the model.
    54→  2. 5 LAYERS: Product (features/UX) → Brain (prompts, RAG, tools, agents) → Backend (gateway, orchestrator, streaming) → Inference (token gen) → Data (Postgres/Redis/vector/S3).
    55→  3. SPEED = 5 compounding tricks: continuous batching + PagedAttention (~20x throughput), prompt caching (~90% cost / ~85% latency cut on cached prefix), speculative decoding (2-3x, identical output), MoE (Kimi K2: 1T params, ~32B active/token), model routing (~60% savings). Plus quantization + geo-distribution.
    56→  4. STREAMING RULE: start SSE (simple, auto-reconnect); move to WebSockets only for mid-stream client input (stop button, live tools, collab/voice).
    57→  5. REQUEST LIFECYCLE: gateway (auth/rate-limit) → orchestrator (history+retrieval+tools+system prompt) → inference → stream tokens → persist + memory update.
    58→  6. RAG PIPELINE: ingest → chunk (300-500 tok) → embed → vector store → hybrid search (keyword+vector) + rerank. Skip RAG if KB fits in context window.
    59→  7. MEMORY LADDER: truncation → rolling summarization → vector long-term memory → hybrid (verbatim recent buffer + session summary + retrieved cross-session facts).
    60→  8. RELIABILITY: smart LB, cost-aware autoscaling, rate limiting/queues, circuit breakers/failover, health checks, multi-region, observability (Grafana + Langfuse/LangSmith).
    61→  9. SAFETY: guardrails at gateway (input/output filtering, LlamaGuard-class classifiers), tool permissioning — destructive tools need confirmation.
    62→  10. DATA DEFAULTS: Postgres (+pgvector first), Redis for sessions/rate-limits/semantic cache, S3 for files.
    63→  11. COSTS: inference = utility bill, 40-50% of early revenue; API $0.20-21/M tok; open MoE <$1/M; build phases 0-3 (prove → MVP/SSE → RAG+guardrails+billing → routing/scale).
    64→- RELEVANCE TO OUR STACK: mobile (Ktor) + Next.js backend; z-ai-web-dev-sdk = "rented brain" in sandbox; stop-generating button → WebSocket (matches sandbox socket.io setup); hybrid memory for mobile assistant; single /chat endpoint with filter-style params (lesson: API design from previous lesson).
